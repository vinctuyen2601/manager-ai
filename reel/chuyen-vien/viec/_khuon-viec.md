# Khuôn một tệp việc

Chép khuôn này khi viết việc mới. Giữ tệp việc **dưới ~120 dòng**; kiến thức dài để trong gói và dẫn tới.

```markdown
# <Vai> · <tên-việc>

## Hợp đồng
| | |
|---|---|
| Khi chạy | <luồng nào gọi, ở bước nào; hoặc ai giao lẻ> |
| Nhận | <phiếu giao + tệp nào> |
| Giao | <tệp nào, theo khuôn nào> + phiếu giao |
| Xong khi | <điều kiểm được> |

## Luật bắt buộc (≤ 5, dạng "Nếu … → …")
1. Nếu … → …

## Bước
1. … (dẫn mục gói: `../<vai>.md` §x)

## Khuôn đầu ra
<khuôn có ô bắt buộc; ô trống = chưa xong>

## Thành công khi
- …
## Thất bại khi (lấy từ bài thi và việc thật, kèm ngày)
- …

## Bộ thi
`<việc>.thi/` — đề, bẫy, cách chấm, điểm các lần thi.
```
